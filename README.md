# Medical Fact-Check Platform

An AI-powered web application for discovering, translating, and verifying medical claims from videos, specifically supporting Darija and Arabic audio.

## Features
- **Video Analysis Studio**: Extract audio from YouTube/TikTok, transcribe it, translate it to English natively via Transformers, and verify the medical claims.
- **Glassmorphism UI**: High-end Next.js frontend with dark-themed premium design.
- **Robust NLP Pipeline**: Offline claim extraction and Translation via HuggingFace Transformers.
- **FastAPI Backend**: Resilient and scalable verification service.
